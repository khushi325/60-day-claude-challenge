# ⚖️ Day 48 – The Verdict Engine with Claude AI

## 📌 Overview

On Day 48 of the 60 Days Claude AI Challenge, I built and explored an interactive **The Verdict Engine** using Claude AI.

The application demonstrates how AI-assisted research can support structured decision-making by comparing different options against user-defined criteria. A key feature of this project is the ability to adjust criteria weights and observe how the rankings change in real time.

The application also provides source-level transparency, allowing users to inspect where each data point came from and review how conflicting information was researched and resolved.

---

## 🎯 Objective

- Learn how weighted decision-making works.
- Compare multiple options using defined criteria.
- Understand how changing weights affects rankings.
- Trace individual data points back to their sources.
- Review how conflicting research information is handled.
- Understand the importance of evidence-based decision-making.

---

## ⚖️ About The Verdict Engine

The Verdict Engine is an interactive decision-support application that combines:

- Weighted criteria
- Live ranking updates
- Source transparency
- Research evidence
- Conflict resolution
- Decision analysis

Instead of simply producing a final answer, the application allows users to understand **why** an option receives a particular ranking.

---

## 📊 Weighted Criteria

The application allows users to assign different importance levels to evaluation criteria.

Changing the weight of a criterion immediately affects the overall ranking.

This demonstrates how the same options can receive different rankings depending on what the decision-maker considers most important.

---

## 🔄 Live Ranking

One of the key features of the application is the dynamic ranking system.

When criteria weights are adjusted:

- Scores are recalculated
- Rankings update automatically
- Users can observe which criteria influence the final result
- Different decision priorities can be tested

---

## 🔎 Sources Panel

The Sources panel provides transparency for the information used in the analysis.

Users can review:

- Individual data points
- Supporting sources
- Evidence behind the evaluation
- Information used to calculate scores

This makes the decision process easier to audit and understand.

---

## 🧪 Research Transparency

The **"How this was researched"** panel explains how the underlying information was investigated.

It also highlights:

- Research methodology
- Conflicting information
- How conflicts were evaluated
- How the final information was selected

---

## 💡 Biggest Learning

A decision is more trustworthy when users can understand both **the result and the evidence behind it**.

Weighted decision-making also shows that there is not always one universally correct answer—the outcome can depend on which factors matter most.

---

## 🌟 Biggest Insight

> AI-powered decision systems become more useful when they combine ranking with transparency, evidence, and explainability.

---

## 📚 What I Learned

- Criteria weights can significantly influence decision outcomes.
- Live scoring makes complex comparisons easier to understand.
- Source transparency improves trust in AI-generated analysis.
- Conflicting information should be investigated rather than ignored.
- Evidence-based decision-making is more reliable than relying only on a final score.
