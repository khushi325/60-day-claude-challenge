## 🧠 Priorly MVP

Priorly is designed to help users answer:

> **"What should I work on right now?"**

Instead of functioning as a simple task list, Priorly uses multiple factors to help determine task priority, including:

- Deadlines
- Personal goal alignment
- Available time
- Energy level
- Task effort
- Importance
- Task dependencies

The system provides an explainable prioritization experience so users can understand **why a task is ranked where it is**.

---

## 🤖 Claude Integration

Claude is integrated as a core part of Priorly.

The AI is used for:

### 1. Freeform Task Parsing

Users can describe multiple tasks naturally, and Claude can help convert the information into structured task data.

### 2. Explainable Prioritization

Claude helps analyze the available task information and generate priority recommendations with understandable reasoning.

The AI integration is handled through the backend rather than exposing sensitive API credentials in the frontend.

---

## 💾 Persistence

Priorly uses persistent storage so that the user's:

- Tasks
- Goals
- Progress
- Completion status

can remain available across sessions.

The V1.0 remains intentionally single-user without authentication or multi-user account management.

## 📚 What I Learned

- Completing an MVP requires integration, not just individual features.
- A working simplified feature is better than an ambitious incomplete feature.
- Local testing and live testing can reveal different problems.
- Deployment should be treated as part of development rather than something saved for the very end.
- AI features need to be meaningful and reliable rather than added only for the sake of using AI.
- Keeping the original scope protected makes a 10-day project achievable.

---

## 💡 Biggest Learning

> **An MVP isn't finished when the code works locally. It's finished when the complete user experience works reliably from start to finish.**
