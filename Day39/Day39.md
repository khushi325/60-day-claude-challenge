# 📄 Day 39 – PDF Splitter & Merger with Claude AI

## 📌 Overview

On **Day 39** of the **60 Days Claude AI Challenge**, I built and explored an interactive **PDF Splitter & Merger** application using Claude AI.

This application allows users to efficiently split PDF files into individual pages or selected page ranges and merge multiple PDF documents into a single file. Before generating the application, Claude asked a few interview questions to customize the features and user experience.

The project demonstrates how AI can accelerate the development of practical productivity tools with an intuitive interface and seamless PDF processing capabilities.

---

# 🎯 Objective

- Build a user-friendly PDF utility application.
- Split PDF documents by page or page range.
- Merge multiple PDF files into a single document.
- Preview uploaded and processed PDFs.
- Download processed PDF files.
- Understand how AI can simplify productivity application development.

---

# 📄 About the Application

PDF Splitter & Merger is a browser-based utility that enables users to organize PDF documents without requiring external software.

The application includes:

- Claude-guided customization
- PDF Splitter
- PDF Merger
- PDF Preview
- Download Processed Files
- Drag-and-Drop Upload Support
- Responsive User Interface

---

# 🔄 Application Workflow

The application follows these stages:

1. Answer Claude's Interview Question
2. Generate the HTML Application
3. Open the Application in Browser
4. Upload PDF Files
5. Test PDF Splitter
6. Test PDF Merger
7. Preview Processed PDFs
8. Download Final PDF Files

---

# ✂️ PDF Splitter

The splitter feature allows users to:

- Split all pages into separate PDFs
- Split selected page ranges
- Preview selected pages
- Download generated PDF files

This feature is useful for extracting specific sections from large PDF documents.

---

# 📑 PDF Merger

The merger feature enables users to:

- Upload multiple PDF documents
- Arrange file order
- Merge all selected PDFs
- Preview the combined document
- Download the merged PDF

This simplifies document organization and sharing.
